# 鼠标划船与冰霜行者增强

适用于 Minecraft Java Edition 1.21.11 + Fabric。

## 鼠标划船

- 鼠标左右移动控制船头方向。
- `W`、`S` 仍负责前进和后退。
- `A`、`D` 不再让船转向，避免与鼠标控制冲突。
- 离开船后，鼠标和键盘行为完全恢复原样。

## 冰霜行者

- I 级：保持原版效果，在水面生成会融化的霜冰。
- II 级：生成普通冰，不需要站在水面或地面上。
- III 级：生成浮冰，不需要站在水面或地面上。
- IV 级：生成蓝冰，不需要站在水面或地面上。

II-IV 级由服务端代码直接冻结玩家脚下一层的水，在水下移动或腾空时也能生效，不要求玩家着地，也不要求水面上方为空气。生成的冰不会像霜冰一样自动融化。

## 安装

1. 安装适用于 Minecraft 1.21.11 的 Fabric Loader。
2. 将 `mouse-boat-steering-1.1.1.jar` 放入游戏的 `mods` 目录。
3. 不需要 Fabric API。
4. 单人游戏只需安装在客户端；多人游戏若要使用增强冰霜行者，服务器也必须安装本模组。

## 构建

需要 JDK 21：

```bash
./gradlew build
```

成品位于 `build/libs/`。
