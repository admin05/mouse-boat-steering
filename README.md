# 鼠标划船与冰霜行者增强

适用于 Minecraft Java Edition 1.21.11 + Fabric。

## 鼠标划船

- 鼠标左右移动控制船头方向。
- `W`、`S` 仍负责前进和后退。
- `A`、`D` 不再让船转向，避免与鼠标控制冲突。
- 离开船后，鼠标和键盘行为完全恢复原样。

## 冰霜行者

- I 级：保留并保持原版效果，在水面生成会融化的霜冰。
- II 级：将空气、水或普通方块替换成普通冰。
- III 级：将空气、水或普通方块替换成浮冰。
- IV 级：将空气、水或普通方块替换成蓝冰。

模组代码会把冰霜行者的最大等级从 II 调整为 IV。II-IV 级不要求玩家着地，也不要求脚下有水；生成范围会把空气、水和普通方块替换成对应冰块。为避免直接破坏重要数据，基岩、屏障、传送门和带方块实体的方块不会被替换。玩家向上跳跃时，每次离地会在脚下生成一层冰并站到新冰层上，可以连续跳跃向上搭建。II-IV 级生成的冰不会像霜冰一样自动融化。

## 安装

1. 安装适用于 Minecraft 1.21.11 的 Fabric Loader。
2. 删除旧版 JAR，只将 `mouse-boat-steering-1.1.3.jar` 放入游戏的 `mods` 目录。
3. 不需要 Fabric API。
4. 单人游戏只需安装在客户端；多人游戏若要使用增强冰霜行者，服务器也必须安装本模组。

## 构建

需要 JDK 21：

```bash
./gradlew build
```

成品位于 `build/libs/`。
