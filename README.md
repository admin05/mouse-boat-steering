# 鼠标划船与冰霜行者增强

适用于 Minecraft Java Edition 1.21.11 + Fabric。

## 鼠标划船

- 鼠标左右移动控制船头方向。
- `W`、`S` 仍负责前进和后退。
- `A`、`D` 不再让船转向，避免与鼠标控制冲突。
- 离开船后，鼠标和键盘行为完全恢复原样。

## 冰霜行者

- I 级：保留并保持原版效果，在水面生成会融化的霜冰。
- II 级：生成 `3×3` 普通冰道，并替换范围内的空气、水或普通方块。
- III 级：生成 `3×3` 浮冰道，并替换范围内的空气、水或普通方块。
- IV 级：生成 `3×3` 蓝冰道，并替换范围内的空气、水或普通方块。

模组代码会把冰霜行者的最大等级从 II 调整为 IV。II-IV 级不要求玩家着地，也不要求脚下有水；生成范围会把空气、水和普通方块替换成对应冰块。为避免直接破坏重要数据，基岩、屏障、传送门和带方块实体的方块不会被替换。玩家向上跳跃时，每次离地会在脚下生成一层冰并站到新冰层上，可以连续跳跃向上搭建。II-IV 级生成的冰不会像霜冰一样自动融化。

手持带有冰霜行者附魔的鞋子按 `C`，可关闭生冰；再次按 `C` 恢复生冰。按键可以在游戏的按键设置中修改。

## 安装

1. 安装适用于 Minecraft 1.21.11 的 Fabric Loader 和 Fabric API。
2. 删除旧版 JAR，只将 `mouse-boat-steering-1.2.0.jar` 放入游戏的 `mods` 目录。
3. 单人游戏安装在客户端；多人游戏的客户端和服务器都必须安装本模组与 Fabric API。

## 构建

需要 JDK 21：

```bash
./gradlew build
```

成品位于 `build/libs/`。
